# Golf Launch Monitor Analysis

## Overview

This project analyzes launch monitor data collected from amateur golfers to determine which factors most strongly influence carry distance.

The analysis was completed in Python using Google Colab.

---

## Research Questions

- Does club speed predict carry distance?
- Which launch monitor variables best predict carry distance?
- Do golfers aged 50+ and 60+ perform differently?

---

## Dataset

Variables include:

- Age
- Handicap
- Club Speed
- Launch Angle
- Push
- Carry Distance
- Total Spin
- Spin Axis

---

## Data Cleaning

- Removed duplicate observations
- Removed topped shots with zero carry
- Created age group categories
- Checked for missing values

---

## Methods

- Exploratory Data Analysis
- Correlation Matrix
- Scatterplots
- Simple Linear Regression
- Multiple Linear Regression
- Residual Diagnostics
